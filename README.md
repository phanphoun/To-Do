# Smart To-Do List

A modern, responsive, and feature-rich To-Do List web application built with HTML, CSS, and JavaScript, using IndexedDB for local storage.

![To-Do List Screenshot](https://via.placeholder.com/800x500.png?text=Smart+To-Do+List+Screenshot)

## Features

- 📅 **Calendar View**: Visualize your tasks on a monthly calendar
- ⏰ **Task Management**: Add, edit, and delete tasks with ease
- 🏷️ **Priority Levels**: Set task priorities (Low, Medium, High)
- 🔔 **Reminders**: Set alarms for important tasks
- 📱 **Responsive Design**: Works on desktop and mobile devices
- 💾 **Offline Support**: All data is stored locally in your browser
- 🎨 **Clean UI**: Modern and intuitive user interface

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- No installation required!

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/phanphoun/To-Do.git
   ```
2. Open `index.html` in your web browser

## Usage

1. **Adding a Task**
   - Fill in the task details (time, description, priority)
   - Click "Add Task"

2. **Editing a Task**
   - Click the pencil icon (✎) on any task
   - Make your changes
   - Click "Save"

3. **Marking Tasks as Complete**
   - Click the checkmark (✓) next to a task
   - Click again to mark as incomplete

4. **Deleting Tasks**
   - Click the 'x' button on any task
   - Confirm deletion

5. **Using the Calendar**
   - Navigate through months using the arrow buttons
   - Click on any date to view tasks for that day
